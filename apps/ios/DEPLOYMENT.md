## Pre-Deployment Checklist

### 1. Run QA Agents on Production

```bash
# Run full QA suite against production
./scripts/qa-runner.sh production

# Expected: 0 failures, warnings are acceptable
```

### 2. Verify Production API Health

```bash
# Check production health
curl -s https://api.dollor.ai/health | jq .

# Expected response:
# {
#   "status": "healthy",
#   "version": "1.0.x",
#   "database": "connected",
#   "timestamp": "..."
# }
```

### 3. Verify Demo Accounts Work

```bash
# Customer login
curl -s -X POST "https://api.dollor.ai/api/auth/customer/login" \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "username=demo.customer@dollor.ai&password=DemoCustomer2025!" | jq .access_token

# Driver login
curl -s -X POST "https://api.dollor.ai/api/auth/driver/login" \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "username=demo.driver@dollor.ai&password=DemoDriver2025!" | jq .access_token

# Restaurant login
curl -s -X POST "https://api.dollor.ai/api/auth/vendor/login" \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "username=demo.restaurant@dollor.ai&password=DemoRestaurant2025!" | jq .access_token
```

## Backend Deployment

### Deploy to Staging First

```bash
# From backend directory
cd apps/web/p2p-platform/backend

# Deploy to staging
git push origin main
# GitHub Actions will auto-deploy

# Wait for deployment, then verify
curl -s https://api.dollor.ai/health | jq .
```

### Deploy to Production

```bash
# After staging verification, promote to production
# Option 1: GitHub Actions workflow dispatch
gh workflow run deploy-production.yml

# Option 2: Manual ECS deployment
aws ecs update-service --cluster dollor-production --service p2p-backend --force-new-deployment
```

### Verify Production Deployment

```bash
# Wait 2-3 minutes for deployment
sleep 180

# Verify health
curl -s https://api.dollor.ai/health | jq .

# Run QA agents
./scripts/qa-runner.sh production
```

## iOS App Deployment

### Build All Apps

See [TESTFLIGHT_BUILD_GUIDE.md](TESTFLIGHT_BUILD_GUIDE.md) for detailed steps.

```bash
# Quick build commands
cd apps/ios

# Archive all three apps
for app in customer delivery restaurant; do
  cd $app
  xcodebuild -workspace *.xcworkspace -scheme * -configuration Release archive -archivePath build/*.xcarchive -allowProvisioningUpdates
  cd ..
done
```

### Upload to TestFlight

```bash
# Upload all apps
fastlane run upload_to_testflight \
  ipa:/path/to/Dollor.ipa \
  api_key_path:$APP_STORE_CONNECT_API_KEY_PATH \
  skip_waiting_for_build_processing:true
```

## Rollback Procedures

### Backend Rollback

```bash
# List recent deployments
aws ecs describe-services --cluster dollor-production --services p2p-backend

# Rollback to previous task definition
aws ecs update-service --cluster dollor-production --service p2p-backend --task-definition p2p-backend:PREVIOUS_VERSION
```

### iOS Rollback

TestFlight builds cannot be rolled back. If critical issue:
1. Submit a new build with the fix
2. Expire the problematic build in App Store Connect

## Monitoring

### Production Logs

```bash
# View ECS logs
aws logs tail /ecs/dollor-production/p2p-backend --follow

# View recent errors
aws logs filter-log-events \
```
